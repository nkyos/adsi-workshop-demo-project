# 打刻メモ機能 — 要件 Q&A

## 1. 基本仕様

[Question] メモを入力できるタイミングはいつですか？（出勤打刻時のみ / 退勤打刻時のみ / 両方 / 打刻後いつでも編集可能）
[Answer] 出勤退勤両方。

[Question] メモの入力は任意ですか？それとも特定の条件（例: 遅刻時）では必須にしますか？
[Answer] 任意。

[Question] メモの最大文字数に制限はありますか？（例: 100文字、200文字、制限なし）
[Answer] 20文字。

## 2. 表示・参照

[Question] メモはどこに表示しますか？（打刻画面に表示 / 勤怠履歴一覧に表示 / 詳細画面に表示 / 複数箇所）
[Answer] 勤怠履歴一覧。

[Question] 管理者（上長）はチームメンバーのメモを閲覧できますか？
[Answer] はい。

## 3. 編集・削除

[Question] 打刻後にメモを編集・削除することは可能ですか？可能な場合、期限はありますか？（例: 当日中のみ / いつでも可 / 不可）
[Answer] 編集可能。

[Question] メモの編集・削除履歴を残す必要はありますか？（監査目的）
[Answer] ない。

## 4. 用途・内容

[Question] メモの想定される用途は何ですか？（例: 遅刻理由の記録 / 業務内容のメモ / 直行直帰の記録 / 自由記述）
[Answer] 遅刻理由。

[Question] メモにカテゴリやタグ（例: 「遅刻」「直行」「早退」）を付ける機能は必要ですか？
[Answer] 不要。

## 5. データ構造

[Question] メモは出勤・退勤それぞれに1つずつ持てるようにしますか？それとも1日の打刻レコードに対して1つのメモですか？
[Answer] それぞれ。

## 6. 検索・フィルタ

[Question] メモの内容で勤怠履歴を検索・フィルタする機能は必要ですか？
[Answer] いらない。

## 7. 追加質問（第2ラウンド）

[Question] 「編集可能」とのことですが、編集の期限はありますか？（いつでも可 / 当日中のみ / 翌月締めまで）
[Answer] いらない。

[Question] メモの削除は可能ですか？それとも空文字に編集することで実質削除としますか？
[Answer] 空文字で実質削除。

[Question] 打刻時のメモ入力 UI はどのような形にしますか？（打刻ボタンの横にテキスト欄を常時表示 / 打刻ボタン押下後にダイアログで入力 / 打刻後に入力欄が表示される）
[Answer] 打刻押下後にダイアログ。

[Question] メモの編集はどこから行いますか？（勤怠履歴一覧の各行から編集 / 打刻画面で当日分を編集）
[Answer] 勤怠履歴一覧から。

[Question] 管理者がメモを閲覧する画面は既存のチーム勤怠一覧（/api/attendance/team）に含める形でよいですか？
[Answer] はい。

## 8. 追加質問（第3ラウンド）

[Question] 打刻ダイアログでキャンセルした場合の挙動: 「打刻ボタン押下 → ダイアログ表示 → キャンセル → 打刻自体を取り消す」でよいですか？（つまり API 呼び出し前にダイアログを出し、確定後に打刻 API を呼ぶ）
[Answer] はい。打刻辞退を取り消してください。
