# 打刻メモ機能 — 要件定義

## 概要

出勤・退勤の打刻時に、任意で短いメモ（最大20文字）を記録できる機能。主な用途は遅刻理由の記録。

## ユーザーストーリー

- 従業員として、打刻時にメモを入力したい。遅刻理由などを記録するため。
- 従業員として、過去の打刻メモを編集したい。後から理由を追記・修正するため。
- 管理者として、チームメンバーの打刻メモを閲覧したい。勤怠状況を把握するため。

## 機能要件

### F-1: 打刻時のメモ入力

| 項目 | 仕様 |
|------|------|
| 入力タイミング | 出勤打刻・退勤打刻の両方 |
| 必須/任意 | 任意（空でも打刻可能） |
| 最大文字数 | 20文字 |
| 入力 UI | 打刻ボタン押下後にダイアログで入力 |

- 打刻ボタンを押すとダイアログが開き、メモ入力欄と確定ボタンを表示する
- メモを入力せずに確定しても打刻は成功する
- ダイアログをキャンセルした場合、打刻自体も取り消す（打刻実行前にダイアログを表示する）

### F-2: メモの編集

| 項目 | 仕様 |
|------|------|
| 編集可否 | 可能 |
| 編集期限 | なし（いつでも編集可） |
| 削除 | 空文字に編集することで実質削除 |
| 編集履歴 | 不要 |
| 編集導線 | 勤怠履歴一覧の各行から編集 |

### F-3: メモの表示

| 項目 | 仕様 |
|------|------|
| 表示箇所 | 勤怠履歴一覧 |
| 管理者閲覧 | チーム勤怠一覧（既存の /api/attendance/team）で閲覧可能 |
| 検索・フィルタ | 不要 |

### F-4: データ構造

- 1日の打刻レコード（AttendanceRecord）に対して、出勤メモ・退勤メモの2つのフィールドを持つ
- カテゴリ・タグ機能は不要

## 非機能要件

- メモは20文字を超える入力をフロントエンド・バックエンド両方でバリデーションする
- 既存の打刻 API のレスポンスにメモフィールドを追加する（後方互換性あり: null 許可）

## 受け入れ基準

1. 出勤打刻時にダイアログが表示され、メモを入力して打刻が完了する
2. 退勤打刻時にダイアログが表示され、メモを入力して打刻が完了する
3. メモを入力せずに打刻が完了する
4. 20文字を超えるメモは入力できない
5. 勤怠履歴一覧に出勤メモ・退勤メモが表示される
6. 勤怠履歴一覧からメモを編集できる
7. メモを空にすることで削除できる
8. 管理者がチーム勤怠一覧でメンバーのメモを閲覧できる

## 画面フロー

```
打刻画面
  └─ 出勤/退勤ボタン押下
       └─ メモ入力ダイアログ（テキスト欄 + 確定/キャンセル）
            ├─ 確定 → 打刻実行（メモ付き）
            └─ キャンセル → 打刻取消

勤怠履歴一覧
  └─ 各行にメモ表示 + 編集ボタン
       └─ 編集ダイアログ（テキスト欄 + 保存/キャンセル）
```

## API 変更（概要）

| エンドポイント | 変更内容 |
|--------------|---------|
| POST /api/attendance/clock-in | リクエストに `memo` フィールド追加 |
| POST /api/attendance/clock-out | リクエストに `memo` フィールド追加 |
| PUT /api/attendance/{id}/memo | 新規: メモ編集用エンドポイント |
| GET /api/attendance/history | レスポンスに `clockInMemo`, `clockOutMemo` 追加 |
| GET /api/attendance/team | レスポンスに `clockInMemo`, `clockOutMemo` 追加 |

## DB 変更（概要）

`attendance_records` テーブルに以下カラムを追加:

| カラム | 型 | NULL | 備考 |
|--------|------|------|------|
| clock_in_memo | VARCHAR(20) | YES | 出勤時メモ |
| clock_out_memo | VARCHAR(20) | YES | 退勤時メモ |
